# SoEx Library

SoEx is a collection of NuGet packages that allows you to host your POCO service implementations In-Process or using a
a range of differnt transports. It is an iteration on the work by [countincognito ](https://github.com/countincognito) published
in the [Company.Dapr](https://github.com/countincognito/Company.Dapr)
