 # SoEx Library

[SoEx](https://github.com/BlairMoir/SoEx/tree/primary/Library) is a collection of NuGet packages that allows you to host your POCO service implemenations In-Process or using Dapr. It is a small iteration on the work by [Riccardo M Bennett-Lovsey](https://www.riccardos.net/) published in the [Company.Dapr](https://github.com/countincognito/Company.Dapr) repository, broken apart and published as nuget packages to make it easier to consume.
